Conectar otra aplicación

Un ERP, un CRM o un sistema de reportes se conecta con una integración, que un administrador crea en el panel de administración. La integración actúa como una cuenta (una propia o una existente): con sus llaves de API lee y escribe los viajes, posiciones, geocercas, lugares y rutas de esa cuenta, dentro de un límite de solicitudes por minuto. Las llaves se muestran una sola vez y se envían en el encabezado X-API-Key:

curl https://route-map.softwareeasydev.com/api/v1/trips \
  -H "X-API-Key: $ROUTE_MAPS_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"name":"Pedido PED-2041","profile":"TRUCK","metadata":{"order":"PED-2041"}}'

metadata (hasta 4 KB de JSON) vuelve con el viaje y en sus eventos, para relacionarlos con los datos propios. Cada llave tiene permisos:

PermisoPermite
trips:readConsultar viajes, sus recorridos y las posiciones en vivo
trips:writeIniciar, terminar y cancelar viajes y enviar posiciones
geofences:read / geofences:writeConsultar geocercas y comprobar un punto / crearlas, editarlas y borrarlas
places:read / places:writeConsultar lugares / crearlos, editarlos, borrarlos y marcar favoritos
routes:read / routes:writeConsultar rutas guardadas / guardarlas y borrarlas
events:readLeer los eventos con GET /api/v1/events
  • Las respuestas tienen la forma { "success": true, "data": … }; los errores, { "success": false, "error": { "code", "message" } }.
  • GET /api/v1/integrations/me muestra la integración, la cuenta, los permisos y la cuota de la llave.
  • Rutas, búsqueda, tráfico y mapas aceptan la llave sin permisos especiales y la cuentan en la cuota de la integración.
  • Cada respuesta trae X-RateLimit-Limit, X-RateLimit-Remaining y X-RateLimit-Reset. Al pasar el límite la API responde 429 con Retry-After; una llave revocada o vencida, 401 INVALID_API_KEY; un permiso que falta, 403 API_KEY_SCOPE_MISSING.
  • Las llaves son para servidores: no las pongas en el código de una página web o de una app.

Eventos

La plataforma registra trip.started, trip.finished, trip.cancelled, geofence.entered, geofence.exited, region.published y region.disabled. Una integración recibe los de su cuenta y los de la plataforma; con «Recibir los eventos de todas las cuentas», los de todas las personas. Todos tienen la misma forma:

Para leerlos sin webhooks, o ponerse al día después de una caída, usa una llave con events:read. Guarda la posición que devuelve la función y vuelve a llamarla cada pocos segundos (la primera vez, con '0'):

// Procesa los eventos posteriores a `after` y devuelve la posición que hay que guardar.
async function readEvents(after, handle) {
  for (;;) {
    const response = await fetch(
      `https://route-map.softwareeasydev.com/api/v1/events?after=${after}&limit=500`,
      { headers: { 'X-API-Key': process.env.ROUTE_MAPS_KEY } },
    );
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    const { data } = await response.json(); // { items, next, hasMore }
    for (const event of data.items) await handle(event);
    after = data.next;
    if (!data.hasMore) return after;
  }
}

Webhooks

Un webhook recibe los eventos elegidos como POST con el evento en JSON y los encabezados X-RouteMaps-Event (tipo), X-RouteMaps-Event-Id, X-RouteMaps-Delivery y X-RouteMaps-Signature.

  • Responde con un 2xx en pocos segundos (10 por defecto). Si no, se reintenta a los 1 min, 5 min, 30 min, 2 h, 6 h, 12 h y 24 h, y el panel muestra el resultado de cada entrega.
  • Un evento puede llegar más de una vez y el orden no está garantizado: usa X-RouteMaps-Event-Id para no procesarlo dos veces y seq para ordenar.
  • La URL debe ser https:// y de Internet, sin redirecciones.

Verificar la firma

X-RouteMaps-Signature: t=<segundos>,v1=<firma>. La firma es el HMAC-SHA256 en hexadecimal de <t>.<cuerpo> con el secreto del webhook (whsec_…, que el panel muestra una sola vez). Calcúlala sobre el cuerpo tal como llegó, antes de interpretar el JSON, compárala en tiempo constante y rechaza las de más de 5 minutos.

Node.js (Express):

import { createHmac, timingSafeEqual } from 'node:crypto';
import express from 'express';

function verify(secret, header, rawBody, toleranceSeconds = 300) {
  const parts = Object.fromEntries(header.split(',').map((part) => part.trim().split('=')));
  const timestamp = Number(parts.t);
  if (!Number.isInteger(timestamp) || Math.abs(Date.now() / 1000 - timestamp) > toleranceSeconds) {
    return false;
  }
  const expected = createHmac('sha256', secret).update(`${timestamp}.`).update(rawBody).digest();
  const given = Buffer.from(parts.v1 ?? '', 'hex');
  return given.length === expected.length && timingSafeEqual(given, expected);
}

const app = express();
app.post('/route-maps', express.raw({ type: 'application/json' }), (req, res) => {
  if (!verify(process.env.ROUTE_MAPS_WEBHOOK_SECRET, req.get('x-routemaps-signature') ?? '', req.body)) {
    return res.sendStatus(401);
  }
  const event = JSON.parse(req.body.toString('utf8'));
  // event.type, event.account, event.data…
  res.sendStatus(204);
});

Python:

import hashlib
import hmac
import time


def verify(secret: str, header: str, raw_body: bytes, tolerance: int = 300) -> bool:
    parts = dict(part.strip().split('=', 1) for part in header.split(',') if '=' in part)
    try:
        timestamp = int(parts.get('t', ''))
    except ValueError:
        return False
    if abs(time.time() - timestamp) > tolerance:
        return False
    expected = hmac.new(secret.encode(), f'{timestamp}.'.encode() + raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, parts.get('v1', ''))

PHP:

function verify(string $secret, string $header, string $rawBody, int $tolerance = 300): bool {
    $parts = [];
    foreach (explode(',', $header) as $part) {
        [$name, $value] = array_pad(explode('=', trim($part), 2), 2, '');
        $parts[$name] = $value;
    }
    $timestamp = (int) ($parts['t'] ?? 0);
    if ($timestamp === 0 || abs(time() - $timestamp) > $tolerance) return false;
    $expected = hash_hmac('sha256', $timestamp . '.' . $rawBody, $secret);
    return hash_equals($expected, $parts['v1'] ?? '');
}
