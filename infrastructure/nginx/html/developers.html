Una plataforma, lista para integrar.

El mapa, las búsquedas, las rutas y las descargas offline salen de esta misma instalación. El navegador de la aplicación cliente no necesita claves de servicios externos ni una CDN.

Mapa, satélite y relieveRegiones publicadas en PMTiles, con estilo, tipografías, imagen y alturas servidos localmente.
TráficoVías principales y tramos medidos por recorridos propios, en vivo o con lo habitual a esa hora.
RutasTres perfiles vehiculares, paradas intermedias, condiciones e indicaciones en español.
Modo offlineDescargas reanudables, versión y SHA-256 para verificar cada archivo.

Demostración del SDK

Insertar un mapa

<div id="map" style="height: 480px"></div>
<script type="module">
  import { createMap } from
    'https://route-map.softwareeasydev.com/sdk/route-maps.js';

  const platform = await createMap({
    container: 'map',
    region: 'ecuador'
  });
</script>

Satélite, relieve y tráfico

const platform = await createMap({
  container: 'map',
  region: 'guayaquil',
  mapType: 'satellite',          // 'map', 'satellite' o 'relief'
  traffic: true,
  onTrafficStatus: (text) => console.log(text)
});

platform.mapTypes;               // [{ id, label, available }]
platform.setMapType('relief');   // false si la región no publica sus alturas
platform.getMapType();
platform.setTraffic(false);
platform.setOverlay('population', true); // 'precipitation', 'temperature'

Calcular una ruta

import { calculateRoute } from
  'https://route-map.softwareeasydev.com/sdk/route-maps.js';

const route = await calculateRoute({
  origin: { latitude: -2.1960, longitude: -79.8832 },
  destination: { latitude: -2.1709, longitude: -79.9224 },
  profile: 'CAR',
  alternatives: true
});

Descargar un mapa para usarlo offline
